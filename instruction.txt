Build a complete **Nagar Parishad Dhamangaon Railway official website from scratch using ONLY Next.js, TypeScript, and Tailwind CSS.**

**STRICT:** No Node.js backend, no Express.js, no MongoDB, no database, no authentication system, no external backend. This must be a **frontend-only static Next.js website**.

### UI/UX

Create a premium, classic **royal government-style UI** with elegant navy/blue, ivory and subtle gold accents, professional Indian-friendly fonts, beautiful typography, glass/premium cards, subtle Framer Motion animations, smooth hover effects and excellent spacing.

Make it **100% responsive** for mobile, tablet and desktop.

### Static Data Management

Since there is **NO DATABASE**, keep all editable website content inside clean local TypeScript/JSON data files.

Store PDFs, images and documents inside the project's `/public` folder and provide proper download/open functionality.

Create reusable components so notices, ward members, documents, services and departments can easily be updated by editing the data files.
